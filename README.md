# Ahead — pitch deck

A 13-slide pitch for **Ahead**, an AI companion for mental health that plans support
around the week a person actually has ahead of them. Built with team Artifex for a
hackathon. The deck is in Russian.

**Live:** https://yerkhat1.github.io/ahead-pitch/

This repository is the deck only, written as one HTML page with keyboard navigation.
The product itself is not in here.
